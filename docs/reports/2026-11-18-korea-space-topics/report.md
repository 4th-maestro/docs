# 조사의 핵심 전제 {.front}

- **[조사 기준]**

  한국에서 보도된 공간 문제와 국내 공공데이터(공공데이터포털, 서울 열린데이터광장)를 근거로 했습니다. 경쟁 제품과 시장은 국내외를 함께 조사했습니다.

⇒ 문제마다 기사 원문, 데이터마다 포털 화면, 경쟁마다 제품 화면을 캡처했습니다. 확인한 문장은 노란색으로 표시했습니다.

- **[주제 구성]**

  6개 주제를 같은 순서로 설명합니다. 한눈에 보기 카드, 문제, 아이디어와 진행, 공공데이터, 경쟁과 시장 순서입니다.

⇒ 한 주제를 추천하지 않고, 여섯 주제를 같은 기준으로 비교한 뒤 선택 기준을 제시합니다.

- **[수치 확인 수준]**

  데이터 항목은 포털 페이지로 확인했고, 인증키 발급과 실제 API 호출은 하지 않았습니다. 시장 규모는 조사 기관의 공개 요약 기준입니다.

⇒ 같은 시장도 기관마다 정의가 달라 범위로 표시했습니다. 원 보고서는 유료이며 확인하지 않았습니다.

## 응급실 길찾기: 받아줄 응급실을 먼저 찾는 지도

**응급실 길찾기는 실시간 병상, 도착 시간, 수용 가능성을 한 지도에 놓고 병원 순위를 계산합니다.**

국내에는 병상 공개 화면과 상황실 체계가 있고, 이 주제는 판단 보조 화면을 만듭니다.

::: figure 응급실 길찾기 한눈에 보기 | 문제 2.5배, 시장 39억~49억 달러, 점수 18점

자료: 이 장의 원문 자료

### 문제

**구급대가 현장에서 60분 넘게 머문 사례가 2년 사이 2.5배 증가했습니다.**

전체 이송 건수가 13.1% 줄었는데도 30분 초과 이송 비중은 1.9%에서 5.2%로 늘었습니다. 광역응급의료상황실의 병원 선정 처리 시간 중위수는 2025년 27분, 2026년 18분입니다.
