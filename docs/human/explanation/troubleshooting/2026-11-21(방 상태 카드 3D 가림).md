# 방 상태 카드 3D 가림

> **요약** (기준일 2026-11-21)
>
> - 방 상태 카드(Frontend #78) 배포 후, 대시보드 방 3D 보기에서 카드가 위쪽 전체 너비로 3D를 가린다는 보고가 있었음. 브라우저를 확대하면 가림이 커짐
> - 원인은 트윈 화면의 좁은 화면 규칙(760px 이하 카드 위쪽 전체 너비 배치)이 대시보드 안 3D 영역(1440px 화면에서 너비 665px)에도 적용된 것
> - 위쪽 배치는 단독 화면만 적용하고, 좁은 3D 영역은 값 줄만 표시, 접기 버튼과 자동 접힘을 추가함(Frontend #80, main #82)
>

> |---|---|---|
> | 100% | 41%(위쪽 649x242px) | 11%(왼쪽 아래 227x190px) |
> | 150% | 42%(위쪽 566x242px) | 13% |
> | 200% | 측정 안 함 | 12% |

> **다음 작업**: 없음

## 1. 증상: 확대할수록 3D를 덮는 카드

**1-1. 2026-11-21 사용자가 웹 확대 시 현재 상태 카드가 렌더링 전체를 가린다고 보고했습니다.**

배경: 방 3D 보기 왼쪽 아래 카드는 #78에서 고정 범례를 현재 값 카드로 바꾼 것입니다. 단독 화면의 760px 이하에서는 아래 보기 도구와 겹치지 않도록 위쪽 전체 너비로 옮기는 규칙을 함께 넣었습니다.

## 2. 조사 과정: 확대 배율별 3D 영역 측정

**2-1. 가짜 API 대시보드에서 1440x900 화면을 확대 100%, 150%, 200%에 해당하는 뷰포트(1440x900, 960x600, 720x450)로 열고 트윈 iframe 크기와 카드 크기를 측정했습니다.**

| 확인 | 결과 |
|---|---|
| 대시보드 안 3D 영역 | 665x576px(100%), 582x560px(150%), 654x560px(200%) |
| 카드 위치(수정 전) | 3개 배율 모두 위쪽 전체 너비, 높이 242px |
| 대시보드의 방 보기 도구 | 숨김(임베드) |

| 가설 | 판단 | 근거 |
|---|---|---|
| 카드 내용이 많음 | 일부 원인 | 2줄 행 5개, 높이 242~312px |
| 좁은 화면 규칙이 임베드에 적용 | 원인 | 3D 영역 너비가 확대와 무관하게 760px 이하 |

## 3. 원인: 화면 너비 기준 규칙의 임베드 적용

**3-1. 트윈의 좁은 화면 규칙은 iframe 너비 기준이라, 1440px 대시보드 안 3D 영역(665px)에서도 적용되었습니다.**

대시보드는 3D 영역 높이를 고정 크기로 설정해 브라우저를 확대해도 3D 영역 높이는 560px 안팎입니다. 그래서 높이 기준 자동 접힘만으로는 해결되지 않았습니다.

## 4. 해결: 단독 화면 한정 배치와 값 줄 표시

**4-1. 카드 배치와 크기를 3D 영역 기준으로 다시 정했습니다.**

- 위쪽 전체 너비 배치는 보기 도구가 있는 단독 화면에만 적용하고, 임베드는 왼쪽 아래에 배치합니다.
- 3D 영역 너비 760px 이하에서는 값 줄만 표시합니다. 범위·근거 줄은 막대와 접힌 요약으로 대체합니다.
- 머리 줄 "접기/펼치기" 버튼(44px)으로 한 줄 요약(온도, 기류, 습도 판정, 고장)을 표시합니다. 사용자 선택 전에는 3D 영역 높이 520px 이하 또는 너비 480px 이하에서 접힌 상태로 시작합니다.
- 임베드 방 보기의 연동 상태 칩은 오른쪽 아래로 옮겨 카드와 겹치지 않게 했습니다.

## 5. 검증: 3개 확대 배율

**5-1. 수정 후 3개 배율 모두 카드는 왼쪽 아래 227x190px(가림 11~13%)이고, 접힌 상태는 315x62px 한 줄입니다. 연동 상태 칩과 겹침이 없습니다.**

트윈 단독 1280px에서는 범위·근거 줄을 포함한 전체 카드가 유지됩니다. 실제 브라우저 확대 대신 뷰포트 크기로 대체 측정했습니다.

## 6. 교훈: 임베드 화면의 너비 기준 규칙 확인

**6-1. iframe 안 화면의 반응형 규칙은 단독 화면 너비가 아니라 iframe 크기로 판정됩니다. 좁은 화면 규칙을 추가할 때는 대시보드 안 크기(1440px 화면 기준 3D 영역 665px)에서도 확인합니다.**

## 7. 같은 증상 재발 시 확인 순서

1. 대시보드 안 트윈 iframe의 `innerWidth`, `innerHeight`를 확인하십시오.
2. 해당 크기에서 적용되는 `@media` 규칙이 `body.hosted`를 구분하는지 확인하십시오.
3. 카드의 `data-open` 값과 접기 버튼 동작을 확인하십시오.
