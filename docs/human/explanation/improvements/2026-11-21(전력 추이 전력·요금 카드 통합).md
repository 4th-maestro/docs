## 1. 배경: 공간 대비 정보량

**1-1. 사용자가 전력 추이 카드가 공간을 많이 차지하지만 의미 있는 정보를 보여 주지 않는다고 지적했습니다(2026-11-21).**

이전 배치는 [상단 지표 카드 묶음과 전체 너비 전력 추이](2026-11-20%28%EC%83%81%EB%8B%A8%20%EC%A7%80%ED%91%9C%20%EC%B9%B4%EB%93%9C%20%EB%AC%B6%EC%9D%8C%EA%B3%BC%20%EC%A0%84%EC%B2%B4%20%EB%84%88%EB%B9%84%20%EC%A0%84%EB%A0%A5%20%EC%B6%94%EC%9D%B4%29.md)입니다. 제시한 선택지는 판단 정보 추가와 축소, 에너지 카드 안으로 통합, 높이만 축소, 운영 탭에서 제거 4가지입니다. 사용자는 에너지 카드 안으로 통합을 선택했습니다.

## 2. 변경: 카드 안 추이선과 2×2 배치

**2-1. 추이선은 전력·요금 카드의 3칸 아래 줄 전체 너비에 표시하고, 값은 시간을 고를 때 말풍선으로 표시합니다.**

- 구성은 범례 줄(오늘 실선, 어제 점선, 어제 같은 시각 대비 증감률)과 추이선 44px, 시간 눈금 18px입니다.
- 마우스, 터치, 좌우 화살표 키로 시간을 고르면 말풍선이 추이선 위쪽에 오늘·어제 kW를 표시합니다.
- 눈금 있는 그래프와 표는 전력 분석 탭에서 확인합니다. 화면 낭독기용 요약 문장(오늘 누적, 어제 같은 시각, 최대 전력)은 유지했습니다.
- 운영 상태 카드는 두 카드가 나란히 놓이는 1128px 이상에서 4칸을 2×2로 배치합니다. 1칸 줄 배치를 유지하면 운영 상태 카드 아래에 약 100px 빈 공간이 생겼습니다.

## 3. 검증: 4개 너비 화면

**3-1. 수정 전(main)과 수정 후 빌드를 같은 가짜 API로 1440px, 1128px, 1024px, 390px에서 측정했습니다. 4개 너비 모두 가로 넘침이 없고 최소 글자는 14px입니다.**

| 너비 | 3D 도면 시작 위치 | 전력 추이 영역 | 상단 카드 |
|---|---|---|---|
| 1440px | 722 → 411px | 1136×391 → 518×91px | 560×130 → 560×235px 2개 |
| 1128px | 785 → 471px | 824×391 → 362×89px | 404×194 → 404×295px 2개 |
| 1024px | 868 → 554px | 736×391 → 694×89px | 운영 상태 130px, 전력·요금 130 → 231px |
| 390px | 1146 → 854px | 358×397 → 328×118px | 운영 상태 208px, 전력·요금 208 → 338px |

주: 1128px의 전력·요금 카드는 3칸이 좁아 "오늘 전기요금(추정)" 라벨과 단위 "원"이 줄바꿈됩니다. 이번 변경 전부터 있던 현상입니다. 밝은 화면과 어두운 화면은 1440px, 390px에서 확인했습니다.
