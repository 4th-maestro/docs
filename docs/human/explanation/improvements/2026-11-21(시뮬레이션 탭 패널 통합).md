# 시뮬레이션 탭 패널 통합

> **요약** (기준일 2026-11-21)
>
> - 시뮬레이션 탭에 같은 기능의 운전 시뮬레이션 패널이 2개(3D 렌더링 안 트윈 패널, 바깥 카드) 있었고, 안쪽 패널이 3D 일부를 가렸음
> - 안쪽 패널을 숨기고 바깥 카드로 통합함. 안쪽에만 있던 기준 설명 2개와 계산 오류 표시를 바깥 카드로 옮김
>
> | 항목(가짜 API, 1440px) | 이전 | 변경 |
> |---|---|---|
> | 렌더링 안 시뮬레이션 패널 | 300x584px | 없음 |
> | 계산 실패 오류 | 안쪽 패널만 표시 | 바깥 카드에 경고 아이콘과 표시 |
> | 오늘 실측 기준 설명 | 안쪽 패널만 상세 표시 | 바깥 카드에 표시 |
>
> **다음 작업**: 없음

## 1. 배경: 같은 기능의 패널 2개

**1-1. 사용자가 렌더링 안 시뮬레이션 카드와 바깥 카드가 비슷한 기능을 한다며 바깥 카드로 병합하고 안쪽 카드를 없애 달라고 요청했습니다(2026-11-21).**

## 2. 변경: 조건 비교와 누락 항목 이동

**2-1. 조건 항목을 비교한 결과 바깥 카드에 안쪽 패널 조건이 모두 있었고, 설명 2개와 오류 표시만 빠져 있었습니다.**

| 항목 | 안쪽 패널 | 바깥 카드(수정 전) |
|---|---|---|
| 설정온도, 시작·끝, 사람 적은 시간 끄기, 사전 냉·난방 | 있음 | 있음(시간 지정) |
| 오늘 실측 기준 | 있음, 설명 포함 | 있음, 설명 없음 |
| 기준 설명(방마다 켠 시간·설정온도 기록) | 있음 | 없음 |
| 계산 오류("오류:"로 시작) | 표시 | 걸러져 미표시 |

- 트윈은 시뮬레이션 역할에서 `body.p-sim` 클래스를 붙이고, 대시보드 안(`body.hosted`)에서는 시뮬레이션 패널(`#actions`)을 숨깁니다.
- 계산은 바깥 카드가 보내는 `simRun` 메시지로 수행하고, 결과와 오류는 `sim` 메시지로 바깥 카드에 표시합니다.

## 3. 검증: 계산 요청과 오류 표시

**3-1. 가짜 API에서 시간 지정 조건 5개 표시, 렌더링 안 패널 없음, "EnergyPlus로 계산" 후 바깥 카드의 오류 표시를 확인했습니다.**

로컬에는 계산 서버가 없어 결과 표시는 확인하지 못했고, 수정 전 빌드도 같은 오류로 결과가 없었습니다.
