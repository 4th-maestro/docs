## 1. 배경: 등록 건물 층 화면 상단 안내

**1-1. PDF·사진 변환 파이프라인은 자동 추정 공간이 있는 층에 확인 안내를 저장했고, 트윈은 층 화면 상단에 표시했습니다.**

운영 도면 버킷의 트윈 파일 중 이 안내가 있는 건물은 `b-b0qrpf21`(1F~3F)입니다(2026-11-21 읽기 전용 조회).

## 2. 변경: 저장 중단과 표시 제외

**2-1. 파이프라인(`frontend/twin/pipeline/pipeline-core.js`의 `assemble`)은 공간을 찾지 못한 층에만 윤곽 안내를 저장합니다.**

트윈(`frontend/twin/digital-twin.html`)은 "사진에서 자동으로 추정한 공간입니다"로 시작하는 층 안내를 표시하지 않습니다. 저장된 데이터는 수정하지 않았습니다.

## 3. 검증: 층별 안내 비교

**3-1. 가짜 API 트윈 데이터에 1F 윤곽 안내, 2F~5F 자동 추정 안내를 넣고 수정 전후 빌드에서 층을 선택해 안내를 읽었습니다.**

수정 전에는 1F~3F 모두 안내를 표시했고, 수정 후에는 1F 윤곽 안내만 표시했습니다. `tsc`, lint, build, `units.check`, `pdf.check`가 통과했습니다.
