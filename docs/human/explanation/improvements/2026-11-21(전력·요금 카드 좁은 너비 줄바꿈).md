# 전력·요금 카드 좁은 너비 줄바꿈

> **요약** (기준일 2026-11-21)
>
> - 1128~1270px에서 전력·요금 카드 요금 칸의 라벨과 값이 줄바꿈되고, 1128px에서는 값이 칸 밖으로 넘쳤음
> - 칸 배치를 grid에서 flex로 바꿔 라벨과 값을 한 줄로 유지하고, 칸이 부족하면 요금 칸을 다음 줄로 옮김. 1128~1279px은 값 글자 34px에서 28px로 축소
>
> | 항목(가짜 API, 1128px) | 이전 | 변경 |
> |---|---|---|
> | 요금 칸 라벨, 값 줄 수 | 2줄, 2줄(칸 넘침) | 1줄, 1줄 |
> | 상단 카드 높이 | 295px | 245px |
> | 3D 도면 시작 위치 | 471px | 422px |
> | 값 20배 건물 페이지 가로 넘침 | 있음 | 없음 |
>
> **다음 작업**: 없음

## 1. 배경: 칸 너비보다 넓은 라벨과 값

**1-1. 1128~1270px에서는 두 카드가 나란히 놓여 전력·요금 카드 칸 너비가 110~122px로 줄어듭니다.**

요금 칸의 라벨 "오늘 전기요금(추정)"은 약 134px, 값 "84,546원"(34px 글자)은 약 129px입니다. [전력 추이 전력·요금 카드 통합](2026-11-21%28%EC%A0%84%EB%A0%A5%20%EC%B6%94%EC%9D%B4%20%EC%A0%84%EB%A0%A5%C2%B7%EC%9A%94%EA%B8%88%20%EC%B9%B4%EB%93%9C%20%ED%86%B5%ED%95%A9%29.md) 기록에서 확인했고, 사용자가 수정을 요청했습니다.

## 2. 변경: flex 칸 배치와 값 28px

**2-1. 칸 합계가 카드 너비를 초과하면 요금 칸이 다음 줄로 이동하므로, 값 자릿수가 증가해도 칸 밖으로 넘치지 않습니다.**

| 위치 | 변경 |
|---|---|
| 전력·요금 카드 칸 | grid 3열 → flex 줄바꿈, 라벨·값 줄바꿈 금지, 칸 최소 너비는 라벨·값 너비 |
| 1128~1279px 값 글자 | 34px → 28px(두 카드, 743px 이하와 같은 크기) |
| 카드 설명 줄 | 띄어쓰기 단위로만 줄바꿈("20:17까 / 지" → "0시부터 / 20:17까지") |

## 3. 검증: 7개 너비와 큰 값

**3-1. 수정 전후 빌드를 같은 가짜 API로 측정했습니다. 1280px 이상, 1024px, 744px, 390px은 카드 높이와 3D 도면 위치가 변하지 않았습니다.**

| 너비 | 요금 칸 라벨, 값 줄 수 | 카드 높이 | 3D 도면 시작 위치 |
|---|---|---|---|
| 1128px | 2줄, 2줄 → 1줄, 1줄 | 295 → 245px | 471 → 422px |
| 1200px | 1줄, 2줄 → 1줄, 1줄 | 272 → 245px | 449 → 422px |
| 1280px | 1줄, 1줄 | 252px | 429px |
| 1440px | 1줄, 1줄 | 235px | 411px |

주: 값 20배(12,600kWh, 1,690,920원) 조건에서 수정 전에는 1128px 페이지 가로 넘침과 1280px 값 칸 넘침이 있었습니다. 수정 후에는 요금 칸이 다음 줄로 이동해 넘침이 없습니다. 이때 카드 높이는 1128px 350px, 1280px 336px입니다.
