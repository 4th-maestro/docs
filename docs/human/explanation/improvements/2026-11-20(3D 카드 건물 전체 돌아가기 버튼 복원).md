# 3D 카드 건물 전체 돌아가기 버튼 복원

> **요약** (기준일 2026-11-20)
>
> - 앱 안 트윈에서 층·호실 보기로 들어가면 건물 전체로 돌아갈 경로가 없던 문제를, 3D 카드 제목 앞 "건물 전체" 버튼으로 복원함(Frontend #40)
> - 트윈 판단 대기 중 첫 층을 미리 골라 트윈(건물 보기)과 앱(1F) 층이 달라지던 결함도 함께 수정
>
> | 항목 | 이전 | 변경 |
> |---|---|---|
> | 건물 전체로 돌아가기 | 없음(트윈 상단 경로 표시가 앱 안에서 숨겨짐) | 3D 카드 제목 앞 버튼(높이 44px, 운영·시뮬레이션 탭) |
> | 시작 시 앱 층 | 1F(트윈은 건물 보기) | 빈 값(건물 전체) |
>
> **다음 작업**: 390px 화면 확인(앱 메뉴에서 층 선택 후 메뉴가 닫히지 않아 자동 확인 실패)

## 1. 배경: 숨겨진 경로 표시

**1-1. 트윈 자체 상단바(`#bar`)의 "건물 > 층" 경로 표시가 앱 임베드 재구성(Frontend #29)에서 숨겨져, 사용자가 건물 전체로 돌아가는 경로가 없어졌다고 보고했습니다.**

## 2. 변경: 앱 버튼과 층 값 정렬

**2-1. 층이 선택되어 있으면 3D 카드 제목 앞에 "건물 전체" 버튼을 표시하고, 누르면 앱 층을 비워 트윈이 건물 보기로 이동합니다.**

## 3. 검증: 운영·시뮬레이션 탭

**3-1. 1440px에서 시작 시 버튼 없음, 1F 선택 후 버튼 표시, 누르면 트윈이 층 보기에서 건물 보기로 바뀌는 것을 운영·시뮬레이션 탭 모두 확인했습니다.**
