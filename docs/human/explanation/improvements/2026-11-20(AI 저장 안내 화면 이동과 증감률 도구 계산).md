# AI 저장 안내 화면 이동과 증감률 도구 계산

> **요약** (기준일 2026-11-20)
>
> - AI 답변에 반복되던 스케줄 저장 안내 문장을 답변에서 빼고 화면 카드로 옮김. 전력 추이 증감률은 모델 계산 대신 도구 결과(`changePct`)로 제공
> - 3문장 초과 답변은 30문항 중 13건에서 6건으로 감소, 답변의 저장 안내 문장은 0건, 증감률 5건은 모두 도구 값과 일치
>
> | 항목(평가 30문항) | 수정 전(2차) | 수정 후(3차) |
> |---|---|---|
> | 3문장 초과 답변 | 13건 | 6건 |
> | 답변의 저장 안내 문장 | 다수 | 0건 |
> | 증감률 도구 값 일치 | 미측정 | 5/5 |
> | 단일 턴 응답 시간 중앙값 | 4.25초 | 3.65초 |
>
> **다음 작업**: 없음(3문장 초과는 [AI 답변 구조화 응답](2026-11-20%28AI%20%EB%8B%B5%EB%B3%80%20%EA%B5%AC%EC%A1%B0%ED%99%94%20%EC%9D%91%EB%8B%B5%203%EB%AC%B8%EC%9E%A5%20%EB%B3%B4%EC%9E%A5%29.md)에서 0건으로 해결)

## 1. 배경: 긴 답변과 모델 계산 증감률

**1-1. AI 답변이 저장 방법을 매번 문장으로 설명해 길어졌고, 증감률은 모델이 직접 계산했습니다.**

운영자는 답변을 짧게 읽기를 원합니다. 모델이 계산한 수치는 도구 결과와 다를 위험이 있습니다.

## 2. 변경: 안내는 화면, 계산은 도구

**2-1. 저장 안내는 초안 카드(`src/ai/ChatPanel.tsx`)가 표시하고, 전력 추이 도구(`energy_trend`)가 증감률을 함께 반환합니다.**

| 위치 | 변경 |
|---|---|
| 시스템 프롬프트 | 저장 방법 설명 문장 금지 |
| 대화 화면 | 초안이 있으면 저장 안내 표시 |
| 도구 `energy_trend` | `changePct` 반환 |

## 3. 검증: 도구 선택 평가 2차·3차 비교

**3-1. 같은 30문항을 수정 전후로 실행하고, 수치 일치는 JEV 판단과 스크립트로 확인했습니다.**

도구 선택 30/30, JEV 수치 불일치 0건은 수정 전후 같습니다. 상세 수치는 [AI 도구 선택 평가](../research/ai-tool-eval.md) 요약 표입니다.
