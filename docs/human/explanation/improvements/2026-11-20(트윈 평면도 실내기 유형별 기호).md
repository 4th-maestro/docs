# 트윈 평면도 실내기 유형별 기호

> **요약** (기준일 2026-11-20)
>
> - 트윈 층 평면도가 실내기 유형과 관계없이 같은 원으로 표시하던 문제를, 2D 매핑 화면과 같은 유형별 기호로 표시하는 방식으로 개선함(Frontend #45)
> - 트윈 범례와 대시보드 3D 카드 범례에 지금 층의 실내기 유형을 표시함
>
> | 항목(1F, 테스트 데이터 실내기 136대에 6개 유형 배정) | 수정 전 | 수정 후 |
> |---|---|---|
> | 평면도에서 구분되는 실내기 유형 수 | 1종(원, 지름 14px) | 6종(기호, 20×20px) |
> | 범례의 실내기 유형 항목(트윈, 대시보드) | 0개, 0개 | 6개, 6개 |
> | 토출 방향(`rot`) 표시 | 없음 | 기호 회전으로 표시 |
> | 유형(`cls`)이 없는 이전 데이터 | 원 | 원(변경 없음) |
>
> **다음 작업**: 390px 화면 범례 확인(대시보드에서 층을 골라도 트윈이 건물 보기에 머묾, 원인 미확인)

## 1. 배경: 확정한 실내기 유형이 3D 호실 화면에만 보임

**1-1. 도면 변환에서 확정한 실내기 유형(`cls`)은 3D 호실 화면 형상에만 반영됐고, 층 평면도는 모든 실내기를 같은 원으로 표시했습니다.**

운영자는 층 평면도에서 스탠드형과 천장형 카세트를 구분할 수 없었습니다. 2D 매핑 화면(`src/ingest/UnitSymbol.tsx`)과 층 평면도의 표시 방식도 서로 달랐습니다.

## 2. 변경: 2D 매핑 화면과 같은 기호

**2-1. 층 평면도는 `cls`가 있으면 2D 매핑 화면과 같은 모양의 기호를 `rot` 방향으로 회전해 표시합니다.**

| 위치 | 변경 |
|---|---|
| `twin/pipeline/idu-shapes.js` | `iduSymbolSvg`(기호 SVG), `IDU_NAME`(범례 이름) 추가 |
| `twin/digital-twin.html` | 평면도 기호 표시, 범례 "실내기 유형" 항목, 트윈 보고 `ui.idu` |
| `src/App.tsx`, `src/twin.ts` | 3D 카드 범례에 `ui.idu`의 유형 아이콘과 이름 표시 |

기호 본체 색은 기존 원과 같이 가동 상태 색(가동, 정지, 고장)입니다. 범례 이름은 `src/ingest/hvac-types.json`의 `name`과 같습니다. 데이터 연동 규약은 [3D 트윈 임베드 규약](../../reference/twin-embed.md) 8절입니다.

## 3. 검증: 테스트 데이터로 두 테마 캡처

**3-1. 제6공학관 데이터의 실내기 136대에 6개 유형과 4개 방향을 돌아가며 넣고, 1F를 열어 표시를 확인했습니다.**

- 1440px 밝은 화면, 어두운 화면: 평면도 기호 6종, 트윈 범례 6개 항목, 대시보드 범례 6개 항목 표시 확인
- 첫 테스트에서 범례 아이콘이 보이지 않았습니다. `vector-effect`는 상속되지 않아 선 두께가 10배로 커졌고, 바탕색 선이 기호를 덮었습니다. 요소마다 `vector-effect`를 지정해 해결했습니다.
- `npm run build`, `oxlint` 통과
- 390px: 미확인. 메뉴에서 1F, 2F를 골라도 트윈이 건물 보기(`v-building`)에 머물렀습니다. 이번 변경과 무관한 층 따라가기 경로라 원인은 확인하지 않았습니다.
