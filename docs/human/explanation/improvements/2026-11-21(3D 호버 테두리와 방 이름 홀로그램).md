# 3D 호버 테두리와 방 이름 홀로그램

> **요약** (기준일 2026-11-21)
>
> - 3D 트윈에서 마우스를 올린 방·층의 테두리가 1px이라 호버 여부를 알기 어려웠고, 3D에는 방 이름이 없었음
> - 굵은 선(방 4px, 층 3px)으로 호버를 표시하고, 방 공간 안에 빛나는 판 형태의 방 이름(홀로그램)을 표시함
>
> | 항목 | 이전 | 변경 |
> |---|---|---|
> | 층 3D 방 호버 테두리 | 1px(WebGL 기본 선) | 4px, 세로 모서리 추가 |
> | 층 3D 방 호버 바닥 채움 불투명도 | 0.19 | 0.32 |
> | 건물 3D 층 호버 테두리 | 1px 색 변경 | 3px 겹침 |
> | 3D 방 이름 | 없음 | 층 3D 모든 방, 건물 3D 마우스 올린 층 |
>
> **다음 작업**: 없음

## 1. 배경: 1px 호버와 이름 없는 방

**1-1. 사용자가 호버 테두리가 너무 얇고, 3D 시점에서 방 이름을 방 공간 안에 홀로그램 느낌으로 표시해 달라고 요청했습니다(2026-11-21).**

WebGL 기본 선(`LineBasicMaterial`)은 굵기 설정과 무관하게 1px로 렌더링됩니다. 표시 범위는 사용자가 "층 3D는 모든 방, 건물 3D는 마우스를 올린 층"으로 정했습니다. 건물 전체 층을 동시에 표시하면 글자가 겹칩니다.

## 2. 변경: 굵은 선과 방 이름 판

**2-1. 호버 테두리는 three.js 굵은 선(`LineSegments2`, `LineMaterial`)으로 렌더링하고, 방 이름은 카메라를 향하는 판(`THREE.Sprite`)으로 렌더링합니다.**

- 방 이름 판: 반투명 판, 위아래 빛나는 선, 빛나는 글자. 방 공간 높이 55%에 표시합니다.
- 크기: 방 짧은 변의 32%(0.8~1.8m), 방 너비의 95%를 넘지 않게 축소합니다.
- 첫 시도는 판 없이 빛나는 글자만(높이 0.45~1.1m) 표시했으나, 밝은 방 상자 위에서 글자가 흐리고 작아 읽기 어려워 판을 추가하고 크기를 키웠습니다.
- 밝은 화면은 흰 판과 진한 파랑 글자를 쓰고, 테마를 바꾸면 다시 만듭니다.

## 3. 검증: 층 3D와 건물 3D

**3-1. 트윈 단독 화면(1280x800, 제6공학관 예시 데이터)의 어두운 화면과 밝은 화면에서 방 호버, 방 이름, 층 호버를 확인했습니다. 페이지 오류는 0건입니다.**

| 확인 | 결과 |
|---|---|
| 층 3D(2F) 방 호버 | "6215 세미나실" 4px 테두리와 세로 모서리 |
| 층 3D 방 이름 | 2F 방 이름 판 표시, 작은 방은 축소 |
| 건물 3D 층 호버 | 5F 3px 테두리, 5F 방 이름만 표시 |

대시보드 안 표시와 저사양 기기 성능은 확인하지 않았습니다.
