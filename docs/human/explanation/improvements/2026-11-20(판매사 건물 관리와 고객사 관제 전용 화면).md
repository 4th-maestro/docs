# 판매사 건물 관리와 고객사 관제 전용 화면

> **요약** (기준일 2026-11-20)
>
> - 고객사 계정은 관제·제어만 하고, 기업·구성원·건물·도면 변경은 판매사 관리자만 하도록 화면과 API를 분리함(Lambda #34, Frontend #24)
> - 판매사 건물 추가(방법 선택, 트윈 파이프라인, 서버 등록), 정보 수정, 도면 편집·교체, 영구 삭제. 건물은 브라우저 저장에서 서버 저장으로 전환
>
> | 항목 | 이전 | 변경 |
> |---|---|---|
> | 고객사 변경 요청 4개 | 고객사 관리자 가능 | 403 |
> | 고객사 화면 관리 버튼, 기업 정보 입력란 | 있음 | 0개, 0개 |
> | 건물 추가 위치·저장 | 운영 화면, 판매사 브라우저 | 판매사 기업 상세, 서버 |
> | 화면 등록 → 서버 처리(가짜 테이블) | 해당 없음 | 등록 201, 교체 200, 겹침 409 |
>
> **다음 작업**: 배포 서버에서 고객사 계정 403 확인(실제 로그인)

## 1. 배경: 역할별 기능 분리 지시

**1-1. 사용자가 판매사는 관리, 고객사는 관제·제어만 하도록 지시했습니다.**

결정 내용은 [판매사 건물 관리와 고객사 관제 전용](../decisions/2026-11-20%28%ED%8C%90%EB%A7%A4%EC%82%AC%20%EA%B1%B4%EB%AC%BC%20%EA%B4%80%EB%A6%AC%EC%99%80%20%EA%B3%A0%EA%B0%9D%EC%82%AC%20%EA%B4%80%EC%A0%9C%20%EC%A0%84%EC%9A%A9%29.md)입니다.

## 2. 변경: 고객사 관리 기능 제거, 판매사 건물 관리 추가

**2-1. 고객사 설정은 기업 정보 조회 화면이 되고, 판매사 기업 상세의 건물 행마다 버튼 5개를 배치합니다.**

| 화면 | 변경 |
|---|---|
| 고객사 운영 탭 | 건물 추가, 수정, 건물 삭제 버튼 제거. 제어 기능 유지 |
| 고객사 기업 정보 | 기본 정보, 건물, 변경 이력 조회만 |
| 판매사 기업 상세 | 정보 수정, 도면 편집, 도면 교체, 연결 해제, 삭제(영구 삭제 확인) |
| 건물 추가 | 도면 이미지(동작), IFC 파일(준비 중) |

## 3. 검증: 교차 검증과 화면 확인

**3-1. 화면이 만든 등록 요청(호실 84개)을 서버 코드로 처리하고, 1440px·390px에서 버튼 높이·너비와 넘침을 확인했습니다.**
