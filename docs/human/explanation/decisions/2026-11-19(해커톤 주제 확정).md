# 해커톤 주제 확정

> **요약** (기준일 2026-11-19)
>
> - 채택: 2D 도면을 3D 공간으로 바꾸고 설비를 자동 배치해 상태·사용량을 보여 주고, 고장 원인을 찾고 최적 운전을 추천하는 정비 기술자용 디지털트윈
> - 이유: 팀 결정(2026-11-19). 정비 기술자가 실제 설비와 트윈을 겹쳐 보며 고장을 찾는 것을 최종 목적으로 정함
> - 범위 결정 4건: 기획·설계 문서 우선, 겹쳐보기는 웹 실측·기대값 비교 기본과 AR 확장, 대상은 건물 기계실·공조 설비, 데이터는 공개 데이터셋과 시뮬레이션
>
> **다음 작업**: 기술 스택 권장안 팀 확인 후 기술 선택 기록 추가(미정)

대체 기록: [과제 4 범위 반영](2026-11-19%28%EA%B3%BC%EC%A0%9C%204%20%EB%B2%94%EC%9C%84%20%EB%B0%98%EC%98%81%29.md)(2026-11-19). 사용자는 건물 운영자로 바뀌었고, 이 기록의 고장 진단은 확장 모듈로 유지합니다.

해커톤 주제 "AI 디지털트윈 기반 공간 가시화 및 운영 최적화"에서 팀이 수행할 서비스를 정한 기록입니다. 서비스 내용은 [서비스 기획](../service-plan.md), 설계는 [시스템 설계](../architecture.md)에 있습니다.

## 1. 배경: 조사 후보 6개 검토 후 팀 결정

**1-1. 2026-11-18까지 조사 보고서 2건에서 주제 후보를 정리했고, 2026-11-19에 팀이 주제를 정했습니다.**

공고의 심사 기준은 결정 시점까지 확인하지 못했습니다.

## 2. 평가 대상: 조사 문서의 후보

**2-1. 후보는 한국 공간 문제 기반 6개와 해외 동향 조사의 후보 5개였습니다.**

| 자료 | 후보 |
|---|---|
| [한국 공간 문제와 주제 6가지](../research/korea-space-topics.md) | 인파 리허설, 응급실 길찾기, 따릉이 재배치, 빈 공간 매칭, 땅꺼짐 위험 지도, 폭염 쉼터 사각지대 |
| [디지털트윈 조사](../research/digital-twin-survey.md) 5절 | A 대화형 공간 트윈, B 재실 기반 공간 운영, C what-if 시뮬레이터, D 이상 징후 작업 지시, E 인파 안전 트윈 |

## 3. 측정 방법: 별도 측정 없음

**3-1. 이번 결정은 팀 판단으로 정했으며, 후보 간 정량 측정은 하지 않았습니다.**

조사 문서의 5개 기준 점수(시장성, 독창성, 구현력, 난이도, 관계성)는 참고 자료로만 사용했습니다.

## 4. 후보: 채택 주제는 해외 동향 조사의 후보 A와 D를 합친 형태

**4-1. 채택 주제는 도면에서 3D를 만드는 후보 A와 이상 징후를 진단하는 후보 D를 합친 구성입니다.**

| 후보 | 이전 점수 | 채택 주제와의 관계 |
|---|---:|---|
| A 대화형 공간 트윈 | 16 | 2D 도면 인식과 3D 생성 부분 |
| D 이상 징후 작업 지시 | 19 | 고장 탐지, 원인 후보, 점검 절차 부분 |
| 한국 주제 6개 | 16~19 | 미채택 |

## 5. 결과: 문제 근거와 데이터 근거 확인

**5-1. 채택 주제는 조사에서 확인한 문제 4개와 공개 데이터 3종에 연결됩니다.**

| 근거 | 내용 |
|---|---|
| 문제 P1 | 정적 3D 모델. 도면과 3D가 갱신되지 않음 |
| 문제 P2 | 설비 데이터 이름 비표준. 매핑 수작업 |
| 문제 P3 | 예측 결과가 정비 작업과 연결되지 않음 |
| 문제 P5 | 시설 운영·기술 인력 68%가 45세 이상(미국 IFMA) |
| 국내 제도 | 기계설비법상 연면적 1만㎡ 이상 건축물 등 유지관리자 선임, 성능점검 연 1회 |
| 데이터 | CubiCasa5K 도면 5,000장, LBNL 공조 고장 데이터 7종, BOPTEST 시뮬레이터 |

## 6. 결정: 정비 기술자용 도면 기반 공조 설비 디지털트윈

**6-1. 서비스는 2D 도면 인식, 3D 생성과 설비 배치, 상태·사용량 표시, 고장 원인 탐지, 최적 운전 추천 5단계입니다.**

| 항목 | 결정 | 결정 방식 |
|---|---|---|
| 사용자 | 정비 기술자(기계설비 유지관리자) | 팀 결정 |
| 최종 목적 | 실제 설비와 트윈을 겹쳐 보며 고장 원인 탐색 | 팀 결정 |
| 겹쳐보기 | 웹 실측·기대값 비교 기본, 태블릿 AR 확장 | 2026-11-19 질문 답변 |
| 대상 | 건물 기계실·공조 설비 | 2026-11-19 질문 답변 |
| 데이터 | 공개 데이터셋과 시뮬레이션 | 2026-11-19 질문 답변 |
| 다음 산출물 | 기획·설계 문서 | 2026-11-19 질문 답변 |

## 7. 운영 시 주의: 기계실 도면 공개 데이터 부족

**7-1. 공개 도면 데이터셋은 주거 평면 중심이라 기계실 도면과 설비 기호는 직접 작성·라벨링해야 합니다.**

- CubiCasa5K는 핀란드 주거 평면 중심입니다. 기계실 설비 기호 공개 데이터셋은 확인하지 못했습니다.
- 공고의 심사 기준이 확인되면 범위(MVP)를 다시 검토하십시오.
- 기술 스택은 [시스템 설계](../architecture.md)의 권장안이며, 팀 확인 후 별도 기록으로 확정합니다.
