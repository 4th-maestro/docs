## 작성 방법

- 파일 이름은 `YYYY-MM-DD(제목).md`입니다. 날짜는 결론을 정한 날입니다.
- 관련 영역 문서에는 결론 1줄과 링크만 추가합니다.
- 결정을 바꾸면 새 기록을 추가합니다. 이전 기록은 삭제하지 않고 요약 바로 아래에 대체 기록 링크를 추가합니다.
- API 키와 개인정보는 기록하지 않습니다.
- 문서 맨 위에는 채택한 방법과 이유를 적은 요약 블록을 작성합니다. 형식은 [문서 작성 안내](../../how-to/write-docs.md) 1절입니다.

본문은 다음 순서로 구성합니다. 절 제목은 `번호. 주제: 결론` 형식이며 `관련 자료` 절에는 번호를 붙이지 않습니다.

| 절 | 내용 |
|---|---|
| 배경 | 도입할 기능, 요구 조건, 결정 시점 |
| 평가 대상 | 비교에 사용한 입력 데이터와 정답 |
| 측정 방법 | 조건, 반복 횟수, 채점 기준, 비용 계산 방법 |
| 후보 | 후보 목록, 단가·제약, 제외한 후보와 제외 이유 |
| 결과 | 후보별 측정값. 실패 사례 포함 |
| 결정 | 선택한 방법과 이유, 대안 |
| 운영 시 주의 | 재측정이 필요한 조건, 측정하지 않은 범위 |
| 관련 자료 | 가격·문서 출처, 관련 코드·화면 문서 |
