## 1. 조사 방법: 국가법령정보센터 서버 응답을 직접 조회

**1-1. 국가법령정보센터 화면은 스크립트로 본문을 불러오므로, 본문을 반환하는 서버 주소를 직접 호출해 원문을 확인했습니다.**

| 대상 | 조회 주소 | 비고 |
|---|---|---|
| 행정규칙 본문 | `https://www.law.go.kr/LSW/admRulLsInfoR.do?admRulSeq=<번호>` | GET 요청으로 HTML 본문 반환 |
| 행정규칙 연혁 | `https://www.law.go.kr/LSW/admRulHstListR.do`(POST `admRulSeq`) | 25개 버전 목록 확인 |
| 법령 본문 | `https://www.law.go.kr/LSW/lsInfoR.do?lsiSeq=<번호>&efYd=<시행일>` | Referer 헤더 필요 |
| 별표 PDF | `https://www.law.go.kr/LSW/flDownload.do?flSeq=<번호>` | `pdftotext`로 추출 |

주: 국가법령정보센터 OPEN API(`DRF/lawService.do`)는 IP 등록이 필요해 사용하지 못했습니다. 산업통상자원부·한국에너지공단 게시 PDF는 사용하지 않았습니다.

**표 1.2 확인 수준 정의**

| 확인 수준 | 의미 |
|---|---|
| 원문 | 발행 기관 사이트의 본문·첨부 파일을 직접 확인 |

| 검색 요약 | 검색 결과 요약으로만 확인, 원문 미열람 |

## 2. 공공기관 실내온도: 냉방 평균 28℃ 이상, 난방 평균 18℃ 이하

**2-1. 현행 고시 제14조 제1항은 난방 평균 18℃ 이하, 냉방 평균 28℃ 이상이며, 같은 수치가 2011-07-26 제정본부터 유지됩니다.**

현행 버전은 기후에너지환경부고시 제2026-111호(2026-04-30 시행)입니다. 2026-04-30 개정 이유는 비전기식 냉방설비 설치 의무 폐지(제10조)와 부처명 변경이며, 제14조 수치는 바뀌지 않았습니다.

## 4. 설계용 실내온도: 냉방 28℃·난방 20℃, 운영 의무 아님

**4-1. 건축물의 에너지절약설계기준 제9조 제1호는 설비 용량계산용 설계기준 실내온도를 난방 20℃, 냉방 28℃로 정한 권장사항입니다.**

현행 버전은 국토교통부고시 제2026-360호(2026-07-08 시행, 타법개정)입니다. 별표 8은 용도별 범위를 제시합니다. 사무소는 난방 20~23℃, 냉방 26~28℃, 냉방 상대습도 50~60%입니다(원문, [별표 8 PDF](https://www.law.go.kr/LSW/flDownload.do?flSeq=167084865)). 별표 8에 난방 습도 열은 없습니다.

## 6. 불쾌지수: 설계 메모 식은 기상청 식과 동일, 서비스는 2020-09 종료

**6-1. 기상청 식 DI = 1.8T − 0.55(1 − RH/100)(1.8T − 26) + 32를 전개하면 설계 메모 식 0.81T + 0.01RH(0.99T − 14.3) + 46.3과 같습니다.**

기온 0~40℃, 습도 0~100% 무작위 1,000개 입력에서 두 식의 차이가 10⁻⁹ 미만임을 계산으로 확인했습니다. 기상청 도움말 페이지는 계산 스크립트에서 습도를 100으로 나누어 사용합니다.

| 항목 | 값 | 출처 | 확인 수준 |
|---|---|---|---|
| 단계 | 매우높음 80 이상, 높음 75~80 미만, 보통 68~75 미만, 낮음 68 미만 | 기상청 도움말 | 원문(웹 보관본) |
| 단계 설명 | 전원 불쾌감, 50% 정도 불쾌감, 불쾌감 시작, 전원 쾌적 | 같은 페이지 | 원문(웹 보관본) |

자료: [기상청 불쾌지수 도움말(2019-12-06 보관본)](https://web.archive.org/web/20191206214325/https://www.kma.go.kr/HELP/basic/help_01_05.jsp), [기상자료개방포털 생활기상지수](https://data.kma.go.kr/data/lwi/lwiRltmList.do), [기상청 저작권정책](https://www.weather.go.kr/kma/guide/copyright.jsp)

**6-2. pythermalcomfort의 불쾌지수는 섭씨 척도 식이라 기상청 단계와 함께 쓸 수 없습니다.**

pythermalcomfort `discomfort_index`는 DI = T − 0.55(1 − 0.01RH)(T − 14.5)이고 경계는 21·24·27·29·32℃입니다(원문, v4.8.1 소스). 운영 도우미가 두 식의 값을 섞어 쓰지 않도록 KB 문서에 차이를 기록했습니다.
