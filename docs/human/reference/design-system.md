> - 공간 시각화는 범례·단위·데이터 기준 시각을 항상 표시. 기준 시각이 갱신 주기의 2배를 초과하면 지연 상태로 표시

Maestro 화면의 데이터 시각화와 상태 표시 기준 문서입니다. 1~3절과 5절의 값이 `DESIGN.md`와 다르면 `DESIGN.md`를 따르십시오. 구성과 규칙은 넉터 디자인 시스템(`_nuktu/doc/human/reference/design-system.md`)을 기준으로 했습니다. 절 번호는 다른 문서에서 참조하므로 변경하지 마십시오.

## <a id="1-색"></a>1. 색: 파랑은 누를 수 있는 요소, 상태는 4종

**1-1. 화면 코드는 색 이름이 아니라 시맨틱 토큰을 사용하고, 파랑은 누를 수 있는 요소와 현재 선택 항목에만 사용합니다.**

안내 카드나 장식 면을 파랑으로 채우면 누를 수 있는 요소와 구분되지 않습니다.

**표 1.1 시맨틱 토큰 초기값과 흰 바탕 대비**

| 토큰 | 값 | 흰 바탕 대비 | 용도 |
|---|---|---|---|
| `canvas` | #FFFFFF | 기준 | 화면 바탕 |
| `surface` | #F3F4F6 | 1.10:1 | 패널·카드 목록 영역 |
| `ink` | #111827 | 17.74:1 | 제목·본문 글자 |
| `graphite` | #4B5563 | 7.56:1 | 보조 글자. 글자에 쓰는 회색의 하한 |
| `steel` | #9CA3AF | 2.54:1 | 비활성 라벨·아이콘·선. 글자 사용 금지 |
| `primary` | #2563EB | 5.17:1 | 버튼·링크·선택 항목 |
| `primaryPressed` | #1D4ED8 | 6.70:1 | 누름 상태 |
| `statusNormal` | #15803D | 5.02:1 | 정상 |
| `statusCaution` | #B45309 | 5.02:1 | 주의 |
| `statusDanger` | #B91C1C | 6.47:1 | 위험 |
| `statusStale` | #6B7280 | 4.83:1 | 데이터 지연 |

주: 대비는 WCAG 2.1 상대 휘도 공식으로 계산. `surface` 위 대비는 `primary` 4.70:1, `statusNormal`·`statusCaution` 4.56:1.

- 색만으로 정보를 전달하지 않습니다. 상태는 색, 아이콘, 글자 중 2가지 이상으로 표시합니다.
- 새 색을 추가하면 표 1.1에 흰 바탕 대비를 계산해 추가합니다.
- 투명도가 필요하면 토큰에 투명도를 적용하는 함수를 사용합니다. hex를 rgba로 직접 변환해 적지 않습니다.

<a id="2-타이포그래피-pretendard-숫자는-고정-폭"></a>

## 2. 타이포그래피: SUIT, 숫자는 고정 폭

**2-1. 폰트는 SUIT Variable 1종이며(2026-11-20 변경, 이전 Pretendard), 수치를 표시하는 표·대시보드는 고정 폭 숫자(`font-variant-numeric: tabular-nums`)를 사용합니다.**

고정 폭 숫자는 값이 갱신될 때 글자 위치 이동을 방지합니다.

| 단계 | 크기/줄높이 | 용도 |
|---|---|---|
| `display` | 28/36 | 대시보드 핵심 수치 |
| `title` | 20/28 | 화면·패널 제목 |
| `body` | 15/22 | 본문 |
| `caption` | 12/18 | 범례·단위·기준 시각 |

## 3. 간격, 라운드, 그림자: 4/8 단위, 그림자 2종

**3-1. 간격은 4의 배수만 사용하고, 그림자는 카드용과 떠 있는 패널용 2종만 사용합니다.**

- 간격: 4, 8, 12, 16, 20, 24, 32
- 화면 좌우 여백: 390px 너비 20, 1440px 너비 32
- 라운드: 8(입력·버튼), 12(카드·패널), 원형(배지)
- 터치 요소 최소 크기: 44

## 4. 아이콘: 라이브러리 1종, 이모지 금지

**4-1. 아이콘은 공개 아이콘 라이브러리 1종만 사용하고, 유니코드 이모지는 코드·목업·문구 어디에도 사용하지 않습니다.**

권장 라이브러리는 Lucide이며, 화면 코드에서는 공통 아이콘 컴포넌트를 거쳐 호출합니다. 다른 아이콘 세트를 섞지 않습니다.

## <a id="5-컴포넌트"></a>5. 컴포넌트: 버튼 높이 쌍 52/40, 주 버튼 화면당 1개

**5-1. 같은 줄에 놓이는 버튼은 높이가 같아야 하고, 너비 비율은 1:1입니다.**

기준은 넉터 디자인 시스템 5.1 가로 배치 규칙입니다.

| 종류 | 높이 | 용도 |
|---|---|---|
| `primary`, `primaryHollow` | 52 | 화면의 주 동작. 화면당 채운 `primary` 1개 |
| `compact`, `outline`, `ghost`, `danger` | 40 | 패널·표·지도 위 보조 동작 |

- 버튼 라벨은 잘리지 않아야 합니다. 1440px와 390px 너비에서 확인하십시오.
- 버튼 라벨은 실행되는 동작을 동사로 적습니다. `확인`, `예`, `아니오`는 사용하지 않습니다.
- 비활성 버튼 위에는 비활성 이유를 1줄로 표시합니다. 비활성 색은 `steel`이며 같은 색의 투명도로 표시하지 않습니다.
- 입력 오류는 해당 필드 바로 아래에 표시합니다.
- 선택지가 5개 이하면 시트나 드롭다운으로 접지 않고 화면에 나열합니다.

## <a id="6-공간-시각화"></a>6. 공간 시각화: 범례, 단위, 기준 시각 상시 표시

**6-1. 3D·평면 화면의 모든 색 표현에는 범례, 단위, 데이터 기준 시각을 함께 표시합니다.**

기준 시각이 없으면 사용자는 화면 값이 현재 상태인지 판단할 수 없습니다.

**표 6.1 공간 시각화 규칙**

| 항목 | 규칙 |
|---|---|
| 연속 값(재실률, 온도, 에너지) | 순차 팔레트 viridis 5단계 #440154, #3B528B, #21908C, #5DC863, #FDE725 |
| 기준 대비 편차 | 발산 팔레트. 중앙값은 `surface` 계열 무채색 |
| 상태(정상·주의·위험·지연) | 표 1.1 상태 토큰과 아이콘·글자 병행 |
| 데이터 기준 시각 | 화면 오른쪽 위 `caption` 크기로 상시 표시 |
| 데이터 지연 | 기준 시각이 갱신 주기의 2배 초과 시 `statusStale`와 지연 아이콘 표시 |
| 선택 객체 | `primary` 외곽선. 면 색은 데이터 색 유지 |
| 카메라 | 초기 시점과 시점 초기화 버튼 제공 |
| 합성·예측 데이터 | 실측 값과 다른 패턴(점선, 음영)과 `예측` 또는 `합성` 라벨 표시 |

주: viridis는 색각 이상 사용자도 단계를 구분할 수 있는 순차 팔레트.

## <a id="7-do--dont"></a>7. Do / Don't: 토큰만 사용, 장식 텍스트·이모지 금지

**7-1. 색·크기·라운드·그림자는 토큰으로만 쓰고, 화면 코드에 하드코딩된 hex·px와 유니코드 이모지를 두지 않습니다.**

**Do**

- 화면 문구 원문은 한국어로 작성합니다.
- 상태는 색, 글자, 아이콘 중 2가지 이상으로 표시합니다.
- 본문 행간은 글자 크기의 1.4배 이상으로 합니다.
- 수치에는 단위와 비교 기준(목표, 이전 값)을 함께 표시합니다.

**Don't**

- 제목 위 작은 영문 대문자 라벨(eyebrow)을 사용하지 않습니다. 예: `02 · IDEA`
- 제목 바로 아래 회색 설명 한 줄(lead)을 사용하지 않습니다. 필요한 정보는 그림 캡션이나 본문으로 옮깁니다.
- 유니코드 이모지를 사용하지 않습니다.
- 한 화면에 채운 `primary` 버튼을 둘 이상 두지 않습니다.
- 읽고 판단해야 하는 글(오류·상태·사유 문구)을 말줄임으로 자르지 않습니다.
- 새 그림자·새 라운드 값을 만들지 않습니다.

## 8. 문서 수정 규칙: 문서를 먼저 수정한 뒤 코드에 반영

**8-1. 디자인 값을 바꿀 때는 이 문서를 먼저 고치고, 색을 추가하면 대비를 계산하고, 컴포넌트를 추가하면 5절에 기록합니다.**

이 문서에 없는 컴포넌트는 다른 담당자가 중복 구현할 수 있습니다.
