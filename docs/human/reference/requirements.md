## 1. 기능 요구사항: 기본 6, 고급 8, 확장 2

**1-1. 과제의 기본(Expectation) 단계는 기능 7개, 고급(Advanced) 단계는 기능 10개이며, 2차 기능 2개를 추가했습니다.**

| ID | 기능 | 구분 | 완료 기준 |
|---|---|---|---|
| FR-01 | 도면 업로드(IFC, DXF, PDF)와 층·호실 표 입력 | 기본 | 시연 건물 도면과 표 업로드 |
| FR-02 | IFC 층·호실·벽 추출 | 기본 | 추출 호실 수가 IFC의 IfcSpace 수와 일치 |
| FR-03 | PDF 벽·호실 인식과 교정 화면 | 기본 | PDF만 있는 층에서 호실 추가·삭제·이름 수정 |
| FR-04 | 3D 생성과 웹 뷰어 | 기본 | 층 전환, 호실 선택 시 이름·용도·면적 표시 |
| FR-05 | 공간-설비 매핑(배치도·IFC 설비 위치) | 기본 | HVAC마다 호실 1곳 연결, 미매핑 목록 표시 |
| FR-06 | 규칙 기반 가상 HVAC 배치 | 기본 | 배치도 없는 호실에 HVAC 생성, "규칙 배치" 표시 |
| FR-07 | 가상 데이터 생성 | 고급 | 예약·재실, 운전, 설정온도, 실내온도, 전력 4주 생성, 시드 고정 |
| FR-08 | 상태 시각화(히트맵) | 고급 | 지표 4종(온도, 전력, 습도, 이상 감지) 전환, HVAC 운전 표시, 범례·단위·기준 시각 표시 |
| FR-09 | 자연어 조회 | 고급 | "현재 전력 사용량이 높은 공간은?"에 상위 호실 목록과 3D 강조 |
| FR-10 | 자연어 제어 명령과 스케줄 초안 | 고급 | "6층 13시 이후 미사용 회의실 냉방 OFF"의 대상이 DB 조건 조회 결과와 일치 |
| FR-11 | 스케줄 확인·저장과 시뮬레이션 반영 | 고급 | 확인 후 저장, 지정 시각 이후 대상 호실 상태 변화 표시 |
| FR-12 | 해석 실패 시 되묻기 | 고급 | 대상 불명확 문장에 후보 선택지 표시 |
| FR-13 | 최적 제어 추천 | 고급 | 규칙 3종으로 낭비 kWh 순위와 개선안 표시 |
| FR-14 | 추천 승인과 전후 비교 | 고급 | 승인 시 스케줄 반영, 적용 전후 전력량 비교 |
| FR-15 | 고장 의심 HVAC 겹쳐보기 | 확장 | 설정온도 미도달 HVAC을 기대값과 비교해 3D 강조 |
| FR-16 | BECON 연동 인터페이스(읽기) | 확장 | 실제 설비 제어 없이 상태 읽기 형식 정의 |
| FR-17 | 질의 의도 파악과 역제안 | 고급 | 답변 마지막에 낭비를 줄일 다음 조치 1개 제안, 대상 불명확 시 되묻기 |
| FR-18 | 사용량 문서 RAG | 고급 | 평균 사용량·사용 빈도 문서를 근거로 답변(Bedrock Knowledge Bases, 비용 점검 후) |
| FR-19 | 도면 기호의 HVAC 모델 매핑 | 기본 | 배치도 기호를 LG HVAC 모델명과 매뉴얼로 연결(모델 담당) |
| FR-20 | 인원·위치 입력 최적 운전 | 2차 | 인원 수와 호실을 입력하면 권장 설정온도와 운전안 제시 |
| FR-21 | 체감온도(불쾌지수) 표시 | 2차 | 온도·습도로 계산한 불쾌지수를 호실 색으로 표시, 계산값 표시 |

## 2. 비기능 요구사항: 응답, 화면, 안전, 데이터 표시

**2-1. 비기능 요구사항은 측정 전 목표값이며, 측정 후 이 표를 실측값으로 갱신합니다.**

| ID | 항목 | 기준 |
|---|---|---|
| NFR-01 | 도면 파싱 시간 | IFC 건물 1개 60초 이내(의원 건물 실험 약 10초) |
| NFR-02 | 자연어 응답 시간 | 조회 5초 이내(목표, 미측정) |
| NFR-03 | 해석 정답률 | 테스트 문장 30개 중 대상 호실·동작 일치 27개 이상(목표 90%, 미측정) |
| NFR-04 | 화면 규칙 | [디자인 시스템](design-system.md) 준수, 범례·단위·기준 시각 상시 표시 |
| NFR-05 | 화면 크기 | 웹 1440px, 태블릿 1024px 확인 |
| NFR-06 | 제어 안전 | 실제 설비 제어 인터페이스 없음, 모든 동작은 시뮬레이션 |
| NFR-07 | 데이터 출처 표시 | 가상 데이터, 규칙 배치, 예측값에 라벨 표시 |
| NFR-08 | 비밀값 | LLM API 키는 `.env`에만 보관, 커밋 금지 |
