# 에게(에너지게이트) 문서 요약

> **요약** (기준일 2026-11-19)
>
> - 에게(에너지게이트, 이전 이름 Maestro)는 해커톤 주제 "AI 디지털트윈 기반 공간 가시화 및 운영 최적화" 프로젝트. 해커톤은 2026-11-19 시작
> - 과제 4(ES 클라우드) 반영(2026-11-19): 건물 운영자가 도면 기반 3D 디지털트윈에서 상태를 보고, 자연어로 조회·스케줄을 만들고, 최적 제어 추천을 받는 서비스. 고장 탐지는 확장
> - 현재 문서는 서비스 기획, 시스템 설계, 요구사항, 기술 조사, 합류 안내, 디자인 시스템. 코드는 `frontend/`(React)와 `lambda/`(AWS SAM)
>
> | 항목 | 현재 값 | 비교 기준 |
> |---|---|---|
> | 기능 요구사항 | 16개 | 기본 6, 고급 8, 확장 2 |
> | 시연 데이터 | 공개 IFC 호실 269개 | 부산대 건물 도면 확보 시 교체 |
>
> **다음 작업**: 부산대 건물 도면 제공 여부 확인, 기술 스택 확정, LLM 비용 점검(미정)
